Chap2: Variable, datatype
*************************
	* Python determines the variable type at runtime.
	* list uses [], tuple uses (), set and dict uses {} and NoneType as none.
	* Python supports complex numbers like 3+4j Here 3 is real and j is imaginary.
	* List, set & dict is Mutable and Tuple, int, float, str, bool is immutable.
	* None represents the absence of a value.
	* type method is being used to knowing the type of variable.
	** Why input() Needs Type Conversion? - Input always returns a string value. To consider it in different type, we need to change its type. Without conversion, it will consider it as string and string concatenation will happen.
	* Multiple assignment : name, age, city = "Manjeet", 30, "Kolkata". We can assign the same value a = b = c = 0
	* Python doesnt have constant variable. for convention, Constant variable are declared in capital letter. Its just a convention.
	
Chap3: Operators
****************
	* An operator is a symbol or keyword used to perform an operation on values or variables.
	* Membership Operators - Used to check whether a value exists inside a sequence such as a string, list, tuple, etc.
		[in] and [not in]
	* Identity Operator - Used to check whether two variables refer to the same object.
		[is] and [is not] [ In python , like JS, there is no ===, it has only == for checking equality/value comparision ]
	* Bitwise Operation - &(And), |(Or) , ^(XOR), ~(Bitwise Not), <<(left shift) and >>(right shift)
	* Unary Operator - An operator works on a single value.
	
	** Operator precedence - 
			()
			**
			+x, -x, ~x
			*, /, //, %
			+, -
			<<, >>
