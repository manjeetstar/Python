chap7: Strings
**************
	* Triple quotes(""") are being used for multi-line strings.
	* Slicing - sequence[start : stop : step]
		Start tells where to begin; stop tells where to stop; step tells which direction to move.		
		If start is missing
			Step is positive → start from the beginning.
			Step is negative → start from the end.
		If stop is missing
			Step is positive → go until the end.
			Step is negative → go until the beginning.
		If both start and stop are missing
			Step is positive → take the sequence from beginning to end.
			Step is negative → take the sequence from end to beginning.
			
		Start is negative
			start is counted from the end.
			With positive step, movement is still left → right.
			With negative step, movement is still right → left.
		Stop is negative
			stop is counted from the end.
			With positive step, you move toward the right, stopping before that negative position.
			With negative step, you move toward the left, stopping before that negative position.
			
		If step is missing, Python always uses +1.
		
	** As we know strings are immutable, we cannot modify the exisiting string. Instead we create a new string.
	
	* Repeating Strings - Use * means print("Manjeet" * 4) op will be ManjeetManjeetManjeetManjeet 		
	* for search, we can use find() method. It Returns the index of the first occurrence.

Chap10: Sets
************
	* A set is unordered, unique elements(Duplicates are automatically removed) only and mutable.
	** x = {} Its not a set, it will be considered as dictionary. 
	   For creating an empty set , x = set()
	* A set does not maintain elements using indexes like a list or tuple.
	*** Python sets can contain different types of values, but there is one important rule:
		Every element in a set must be hashable. tuple, integers, strings, booleans, and floats can all coexist as all are immutable. But a list, dist and set, cannot be an element of a set.
	* Methods:
		Update(): for adding multiple elements into it
		remove() - remove an element. if not present , then it will throw keyError 
		discard() - same as remove but no error in case element is absent
		pop() - remove any arbitary element.
		clear() - clear all the sets
		Sets support mathematical operations such as:
			Union - Union means all elements from both sets, with duplicates removed. A U B
			Intersection - Intersection means elements common to both sets. A & B
			Difference - Difference means elements that are in the first set but not in the second. A - B
			Symmetric Difference - Elements that are in either set, but not in both. A ^ B

				A | B  → EVERYTHING
				A & B  → COMMON
				A - B  → ONLY A
				A ^ B  → NOT COMMON
				
			Subset - A set A is a subset of B if every element of A exists in B. print(A.issubset(B))
			Superset - Here B is superset of A. print(B.superset(A))
			Disjoint - Two sets are disjoint when they have no common elements. print(A.isdisjoint(B))			
		
	* Overall Summary
		1. Set uses { }.
		2. Empty set is set(), NOT {}.
		3. Set stores unique elements.
		4. Set is unordered.
		5. Set does not support indexing.
		6. Set is mutable.
		7. add() adds one element.
		8. update() adds multiple elements.
		9. remove() gives an error if the element doesn't exist.
		10. discard() does not give an error if the element doesn't exist.
		11. pop() removes an arbitrary element.
		12. Sets support union, intersection, difference and symmetric difference.
		13. Set elements must be hashable.
		14. Lists cannot be set elements, but tuples can be.
		
Chap11: Dictionary
******************
	* A dictionary is a Python data structure used to store data in key–value pairs.
	* We access a dictionary using its key, not a numerical index. if key is not present, will result keyError. But when we use .get() method, it doesnt throw any error.
	* Dictionary keys must be of a hashable/immutable type. Rest wont be allowed like list, set. Dictionary is allowed. Keys is only immutable but value can be mutable.
	* update() method adds new items or changes existing items.
	* We can create a dictionary using the dict() function: student = dict(name="Rahul", age=20)
	** Overall Summary
		Dictionary stores data as key-value pairs.
		Keys must be unique.
		Keys must be immutable/hashable; values can be of almost any Python type.
		Dictionary is accessed using keys, not numerical indexes.
		If a key already exists, assigning a value updates it.
		If a key doesn't exist, assigning a value adds a new item.
		in checks keys by default.
		keys(), values(), and items() are used to retrieve dictionary views.
		Dictionaries are mutable, so their contents can be changed after creation.
		An empty {} creates an empty dictionary.
		
chap12: Comprehension
*********************
	* Comprehension Cheat sheet (For List/Set/Dict)
	
		| Type                | Syntax                                        |
		| ------------------- | --------------------------------------------- |
		| List                | `[expression for x in iterable]`              |
		| List + filter       | `[expression for x in iterable if condition]` |
		| List + if-else      | `[a if condition else b for x in iterable]`   |
		| Set                 | `{expression for x in iterable}`              |
		| Set + filter        | `{expression for x in iterable if condition}` |
		| Dictionary          | `{key: value for x in iterable}`              |
		| Dictionary + filter | `{key: value for x in iterable if condition}` |
		| Generator           | `(expression for x in iterable)`              |
	
	** Nested List Comprehension	
		ctr2 =[ b*b for b in [ a for a in ctr if a%2 ==0 ]]
		print(ctr2)
	** List vs Set comprehension [ basically it depends on braces ]
		[ ... ]   → list comprehension
		{ ... }   → set comprehension
