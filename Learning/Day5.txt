Chap27:  Lambda Functions
*************************
	* A lambda function is a small, anonymous function written in a single expression.
		lambda arguments: expression
		The lambda itself creates a function object.
		
	* Lambda vs Normal function
			def                    lambda
			 │                       │
			 ▼                       ▼
			named function          anonymous function
			multiple statements     single expression
			explicit return         implicit return
			
	* Lambda functions can have default arguments. greet = lambda name="Manjeet": f"Hello {name}"
	
	* Lambda with all if..else
	
	* Lambda with Map - map(lambda function, iterables)
		numbers = [1, 2, 3, 4, 5]
		result = map(lambda x: x * x, numbers)
		
	* Lambda with sorted 
			sorted(iterable, key=lambda item: sorting_value)
			
			students = [
				("John", 85),
				("Alice", 92),
				("Bob", 78)
			]
			result = sorted(students, key=lambda x: x[1]) // Here x[1] means sorting based on age.
		For changing the order, result = sorted(numbers, key=lambda x: x, reverse=True)
		
	* Lambda With reduce() - reduce(function, iterable, initializer)
		result = reduce(lambda a, b: a + b, numbers)
		
	* Lambda Inside Another Function - We can return Lambda expression too from a function as well. While calling the function, it returns a lambda expression with held value(even outer function has finished). This is what we call it closure.
	
	* Immediately Invoked Lambda - result = (lambda x: x * x)(5) Here (lambda x: x * x) creates a function expression and (5) is the argument passed to the function.
	* Lambda Limitations
		- You cannot have multiple statements
		- You cannot write normal control-flow blocks
	
	** Lambda in Real Automation/API Testing Here Sorted, min, max so we need to use it as much required.
	   Max : max(data, key=lambda x: x["score"])
	   Min : min(data, key=lambda x: x["score"])
	
	* A higher-order function is a function that:
		1. accepts another function as an argument, or
		2. returns another function. Here in function, we are sending a lambda expression.
		
Chap28:  Functional Programming
*******************************
	* Functional Programming (FP) is a programming style where computation is expressed by applying functions to data, while trying to minimize changing state and side effects.
	
	* We can filter, map and reduce all in a single statement , this is what called functional programming, applying functions on data.
		ages=[10,3,45,32,24]
		result=reduce(lambda a, b: a+b, list(map(lambda y: y*2, filter(lambda x: x%2 == 0, ages))), 0)
		print(result)

	* First-Class Functions - Python treats function as first class function whether it can assigned to a variable or passed as an argument or returned from another function(returning lambda expression)
	
	* A pure function:
		1. Always produces the same output for the same input.
		2. Doesn't modify external state.
	  Impure function
		External state
			 ↑
			 │
		function modifies it
	* A side effect occurs when a function does something beyond calculating and returning a value. like inserting in database or writing in file or hitting any api endpoint etc..
	
	** Function Composition : its like f(g(x) where g is a function and f is a function too. Output of g becomes input of f.
	   we can create our own..
			def compose(f, g):
              return lambda x: f(g(x))
			  
			double = lambda x: x * 2
			square = lambda x: x * x

			operation = compose(square, double)

			print(operation(5))
			
	* Referential Transparency - An expression is referentially transparent when you can replace it with its result without changing program behavior.
	* Functions as Data : data → function → result. Its like in the place of data, we are passing the function expression
			operations = [
				lambda x: x + 10,
				lambda x: x * 2,
				lambda x: x ** 2
			]
			
	* functools — Important Module
		functools.reduce()
		functools.partial()
		functools.lru_cache()
		functools.cache()
		functools.wraps()
		
	** Functional Programming Principles
			1. First-class functions
			2. Higher-order functions
			3. Pure functions
			4. Minimize side effects
			5. Prefer immutability
			6. Function composition
			7. Declarative thinking
			
Chap29: Decorators
******************
	* A decorator is a function that modifies or extends the behavior of another function without changing its source code.
	* Decorator can be used for Logging, Authentication,Authorization,Timing,Retry,Caching,Validation,Metrics,Tracing,Exception handling
	* Decorators depend heavily on the fact that Python functions are objects. You can assign a function to a variable.
	* Pattern of a decorator
			decorator
			   │
			   ├── receives function
			   │
			   └── returns wrapper
						 │
						 ├── before
						 ├── original function
						 └── after
	*  @wraps(func) This is we need to tagged to wrapper method. This is just to save meta data associated with original function, not the wrapper function.
	if we dont do, then print(<original_Method>.__name__) will return wrapper... Other than __name__, other meta data __doc__ and __module__
	 
	* If decorator function has a parameter then the sequence would be like..
			retry()
			   ↓
			decorator()
			   ↓
			wrapper()
			   ↓
			original function
			
		Here we need to return result, followed by wrapper and decorator. Why? Because its a decorator factory so it returns that manyy decorator.
	* we can tag multiple decorator to a function.
		@decorator1
		@decorator2
		def process(): # Here execution order would decorator1 first, followed by decorator2.
		
		process = decorator1(decorator2(process))
		Here output would be
			decorator1 before
			decorator2 before
			TEST
			decorator2 after
			decorator1 after
			
	** Decorator with class : We can define decorator within a class and that can be applied to a method.
	Class-based decorator — __call__ needed, we need to implement within class. __call__ makes an object behave like a function.
		class Log:
		def __init__(self, func):
			self.func = func

		def __call__(self, *args, **kwargs):
			print("Before")
			return self.func(*args, **kwargs)
			
		Then
			@Log
			def calculate(a, b):
				return a + b
		calculate(10,20)
		
		Class decorators are useful for:
			- registration
			- dependency injection
			- configuration
			- metadata
			- plugin systems
