Chapp17: Exception Handling
***************************
	* try..except..else..finally , like JS/TS, it also supports else.
	* Most normal runtime exceptions derive from Exception(Parent class).
	
	* to raise an except, we can use keyword Raise...
	* assert vs raise: assert → mainly for developer assumptions/invariants. raise → explicitly report an application error.
	* raise vs raise e
		raise - Python re-raises the current exception while preserving its traceback.
		raise e - explicitly raises the exception object again and can affect how the traceback is presented.
		
	* we can use return statement as well. The finally block executes before the function actually returns.
	* Bare except vs except Exception - Bare except catches everything. 
	* Exception Handling hierarchy
		BaseException
				│
				├── KeyboardInterrupt
				├── SystemExit
				├── GeneratorExit
				│
				└── Exception
					│
					├── ValueError
					├── TypeError
					├── KeyError
					├── IndexError
					├── FileNotFoundError
					├── ZeroDivisionError
					└── ...
	* In except, we cannot add Exception first and then its subclass. 
	* Multiple exceptions - except (ValueError, TypeError):
	
Chap18: File Handling
*********************
	* read(means all), readLine, write(will delete prev content), writeLines(Multiple lines), append (at the end)
	* "w" if file is not present, it will create a newer one. "x" create mode, if file exists, fileExists exception
	* read, seek(move the cursir), tell(current position)
	* Important Packages - PathLib, JSON, csv
	* for JSON, load mean read, dump means write into file
		with open("user.json", "w") as file:
		json.dump(user, file, indent=4)
		
	* load vs loads - one is read from file and another is from string
	  dump vs dumps - one is write into file and another is writing into string.
	  
	  For CSV, dictReader for reading and writer for writing.
	* Pathlib, unlink() deletes the file.
	** File handling exception
			FileNotFoundError
			PermissionError
			FileExistsError
			IsADirectoryError
			NotADirectoryError
			UnicodeDecodeError
